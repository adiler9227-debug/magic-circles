# Для Gemini: как сделать нового героя для «Магия: Круги Смерти»

Прочитай файлы по порядку (все короткие):

1. `01_engine.md` — на чём игра, как собирается, главные правила.
2. `02_hero_contract.md` — что должна вернуть функция героя: `{g, cast, u}`.
3. `03_classes.md` — где прописаны герои (ID, имена, кнопки, умения, откаты).
4. `04_spawn_scale.md` — откуда вылетают эффекты, масштаб, куда смотрит герой.
5. `05_network.md` — как герой и касты идут по сети + блок `FILES` из `server.js`.
6. `06_glb_template.md` — требования к .glb и **рабочий код**, который уже стоит в игре (маг из Hi3D).

## Два пути

**Путь А — новый облик для существующего героя (рекомендуется начать с него).**
Новая 3D-модель (.glb со скелетом) заменяет внешний вид одного из 5 героев. Умения, сеть, сервер — не трогаются. Так уже сделан маг (`mage.glb`). Нужен только .glb + ~25 строк кода по шаблону из `06_glb_template.md`.

**Путь Б — совершенно новый, шестой герой со своими умениями.**
Нужно менять около 10 мест в коде и `server.js` (там сейчас жёстко номера героев 0–4). Список мест — в `03_classes.md`. Делать только после пути А.

## Что от тебя ждём

1. Концепт героя (оригинальный, не копия чужих персонажей) → картинка → 3D-модель (Hi3D).
2. Модель привести к требованиям из `06_glb_template.md` (≤30 тыс. треугольников, ≤2 МБ, скелет, анимации `cast_hand` / `cast_staff` или свои).
3. Код подключения по шаблону.
4. Ответы владельцу — **по-русски, коротко, одной готовой командой**. Сервер не обновлять без его «да».
