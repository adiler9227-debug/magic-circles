# 4. Откуда вылетают эффекты, масштаб, ориентация

## Точки вылета

Привязки к руке/посоху **нет**. Все умения считают от корня игрока и направления взгляда:

```js
const CS  = () => CTX && CTX.o || ME;            // кто кастует
const CP  = () => CS().g;                        // его группа (позиция на земле, y = 0)
const cyw = () => CS()===ME ? yaw : (CS().yaw||0);
const fwd = () => new THREE.Vector3(-Math.sin(cyw()), 0, -Math.cos(cyw()));   // куда смотрит
const face= (o,F) => { o.g.rotation.y = Math.atan2(F.x, F.z) };               // повернуть героя к F
```

Типичное умение:
```js
const o=CS(), p=CP().position, F=fwd(); face(o,F);
const x=p.x+F.x*2, z=p.z+F.z*2;     // 2 юнита вперёд
km.position.set(x, 2.2, z);          // высота задаётся числом: ~2.2 (пояс/руки), ~4.4 (над головой)
```
Круг при касте (`castFX`) — на земле вокруг `o.g.position`, радиус ~1.5.

Значит: **модель не обязана иметь «точку посоха»**. Главное, чтобы руки/оружие были примерно на высоте 2–4.5 юнита и спереди героя.

## Масштаб

- Герой ≈ **6 юнитов** ростом (маг из .glb — ровно 6.2). Карта 600×600.
- **Ноль по Y — в ногах** (на земле). Модель надо сдвинуть так, чтобы `min.y = 0`.
- Удобно нормализовать при загрузке:
```js
const b=new THREE.Box3().setFromObject(M), s=6.2/(b.max.y-b.min.y);
M.scale.setScalar(s); M.position.y=-b.min.y*s;
```

## Ориентация

- Герой смотрит в **+Z** своей локальной системы (движок делает `g.rotation.y = atan2(F.x, F.z)`).
- Модели из Hi3D уже смотрят в +Z (лицом к камере по умолчанию) — поворачивать не нужно. Если модель смотрит в −Z, поверни внутреннюю группу на `Math.PI`.

## Левитация / ходьба

Шагов нет: герои левитируют/скользят. Покачивание делается кодом в `u(t,mv)`:
```js
W.position.y = .3 + Math.sin(t*1.8)*.14;   // парение
W.rotation.x = mv ? .12 : 0;               // наклон при движении
```
